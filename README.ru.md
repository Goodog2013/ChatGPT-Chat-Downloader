# ChatGPT Chat Downloader · Goodog Chat Export 3.0

[English](README.md) · [Скачать пакет для Windows](https://github.com/Goodog2013/ChatGPT-Chat-Downloader/releases/download/v3.0.0/GoodogChatExport-Windows-3.0.0.zip)

Два режима: ZIP с разговором и оригиналами доступных вложений или прежний TXT с текстом. По умолчанию выбран английский. Переключатель RU / EN меняет интерфейс, статусы и служебные подписи файлов; выбранный язык запоминается. Текст сообщений не переводится. Прокрутка не требуется: сообщения получаются страницами из JSON разговора.

## Установка / обновление

1. Распакуйте GoodogChatExport-Windows-3.0.0.zip в постоянную папку.
2. Для обновления замените файлы в папке extension установленной версии содержимым новой extension и нажмите «Обновить» на chrome://extensions/ или edge://extensions/. Либо удалите старое расширение и загрузите новую папку extension как распакованное расширение.
3. Для первой установки BAT-помощник Установить-Chrome.bat / Установить-Edge.bat откроет папку и страницу расширений. Включите «Режим разработчика», нажмите «Загрузить распакованное», выберите extension с manifest.json.
4. Обязательно перезагрузите вкладку ChatGPT после обновления. Старый загрузчик в открытой странице сам не обновляется.

Нужен Chromium 116 или новее. Python, Node.js и API-ключ OpenAI для использования не нужны. Установочную папку нельзя удалять после загрузки расширения.

## ZIP из открытого разговора

1. Войдите в ChatGPT в том же браузере и откройте нужный сохранённый разговор с /c/… в адресе. Чаты проектов /g/…/c/… тоже поддерживаются.
2. Откройте расширение. Для больших чатов удобно «Открыть в широком окне»; исходную вкладку ChatGPT оставьте открытой.
3. Выберите язык и «ZIP · чат и файлы». Нажмите кнопку получения.
4. Браузер может запросить доступ к хранилищам файлов oaiusercontent.com и blob.core.windows.net. Он нужен для загрузки оригиналов. При отказе история всё равно загружается, но недоступные файлы будут отмечены в отчёте.
5. Дождитесь получения всех страниц, разрешения ссылок и загрузки вложений. Затем выберите место для сохранения ZIP в стандартном окне браузера.

ZIP содержит:

- chat.html — офлайн-страницу сообщений с локальными изображениями, аудио, видео и ссылками на файлы;
- chat.txt — текст текущей ветки, включая код, Markdown, ссылки и прерванные ответы;
- conversation.json — видимые сообщения, их связи и описание вложений без скрытых инструкций, внутренних рассуждений и сессионных реквизитов;
- attachments/ — оригинальные байты доступных файлов;
- manifest.json — список всех обнаруженных вложений с локальным путём, размером и SHA-256 либо причиной отсутствия;
- README.txt — описание состава и ограничений архива на выбранном языке.

Распакуйте ZIP целиком и откройте chat.html. HTML не загружает внешние ресурсы и не запускает скрипты. SVG и HTML-вложения остаются файлами со ссылкой скачивания; они не исполняются внутри страницы чата.

Полнота истории и полнота вложений показываются отдельно. Если файл удалён, отозван, имеет истёкшую ссылку, превышает предел или его формат адреса неизвестен, ZIP всё равно можно сохранить: проблема будет явно указана в manifest.json. Название файла не выдаётся за сохранённый оригинал.

Обычные ссылки на внешние сайты не превращаются в загрузку этих сайтов. Сохраняются распознанные вложения и ссылки на файлы sandbox в тексте вне кода. Поддерживаются ссылки файлов metadata.attachments, image/audio/video asset pointers, доступные изображения инструментов и файлы /mnt/data, если ChatGPT ещё разрешает получить оригинал.

## Что означает «весь чат»

Загрузчик получает текущую выбранную ветку до подтверждённого начала и конца пагинации. Альтернативные ответы не смешиваются с её хронологией в chat.txt и chat.html. Если полученный JSON mapping уже содержит альтернативные видимые узлы, они дополнительно сохраняются в conversation.json вместе с доступными вложениями; поле availableAlternatesCount показывает их число.

Плоский API не гарантирует выдачу всех альтернативных веток. Расширение не выдумывает скрытые маршруты, не открывает другие разговоры и не обещает восстановить удалённые данные. Для более полного дерева используйте conversations.json из встроенного экспорта аккаунта. Скрытые системные инструкции, профили, память и внутренние рассуждения исключены в обоих режимах.

Старые остановленные ответы сохраняются с доступным текстом и не делают историю неполной. Если последний ответ ещё генерируется, это снимок текущего текста; повторите экспорт после окончания ответа для его окончательной версии.

## TXT

Выберите «TXT · только текст». Поведение 2.1 сохранено: весь доступный текст текущей ветки, код, ссылки и текстовые подписи; картинки, бинарные вложения и заглушки файлов не добавляются. TXT сохраняется как UTF-8 с BOM для Windows. Дополнительные разрешения файловых CDN для TXT не нужны.

Из уже полученного разговора можно сохранить другой формат без повторной загрузки всей истории. При смене языка уже собранный TXT может сохранить служебные подписи языка, выбранного при загрузке; для их смены получите чат заново.

## Локальный официальный экспорт

1. Закажите встроенный экспорт данных своего аккаунта ChatGPT и скачайте его.
2. Распакуйте официальный ZIP средствами Windows.
3. В широком окне расширения откройте conversations.json. Поддерживается также отдельный JSON разговора с mapping или messages.
4. Для ZIP дополнительно выберите распакованную папку экспорта с вложениями. Файлы сопоставляются с выбранным разговором по ID и однозначным именам; чужие и неоднозначные файлы не добавляются.
5. Выберите разговор, формат и сохраните результат. Без папки вложений ZIP тоже создаётся, а отсутствующие оригиналы отражаются в manifest.json.

Файлы обрабатываются в памяти браузера, не загружаются на сервер и не требуют сессии ChatGPT. Локальная сборка не делает сетевых запросов за вложениями. Большой conversations.json индексируется потоково в Worker: в памяти удерживается выбранный разговор, а не весь JSON аккаунта одновременно. На время обработки оставьте вкладку расширения открытой.

## Реальные ограничения

- До 256 МиБ на один файл и до 1,5 ГиБ на ZIP. Архив собирается из Blob в памяти браузера; это не потоковая запись ZIP64 на диск. Более крупные вложения отмечаются в отчёте. При нехватке памяти браузера сборка может завершиться ошибкой.
- До 1000 страниц / 250000 объектов сообщений / 256 МиБ входящего JSON за один прямой сбор, не более 8 минут получения истории. Достижение предела даёт частичную историю с предупреждением.
- Внутренние read-only HTTP-контракты ChatGPT недокументированы и могут меняться. Возможность скачать конкретный файл зависит от доступности в аккаунте; это не обещание восстановить истёкшие или удалённые файлы.
- При 401/403, защитной странице или смене рабочего пространства используйте официальный локальный экспорт. Проверки доступа не обходятся.
- ZIP хранится без дополнительного сжатия (STORE): изображения, видео и готовые архивы обычно уже сжаты. SHA-256 указан для каждого успешно добавленного вложения.

## Приватность и разрешения

activeTab и scripting дают доступ к выбранному разговору по явному нажатию; downloads сохраняет локальный файл; offscreen собирает TXT/ZIP. Постоянных host_permissions нет. Optional host permissions двух файловых хранилищ запрашиваются только при действии пользователя для ZIP.

Access token берётся только из собственной активной сессии ChatGPT для точных read-only запросов разговора и разрешения его файлов. Он остаётся внутри вкладки на время операции, не передаётся в background, на файловые CDN или сторонний сервер и не записывается в архив. CDN получают только разрешённый адрес файла без Authorization/cookies. Временные ссылки не входят в публичные JSON/manifest как реквизиты загрузки. Чат не хранится в localStorage или chrome.storage; сохраняется только выбор языка интерфейса.

Исходные реализации контрактов, использованные при подготовке: [chatgpt-exporter](https://github.com/pionxzh/chatgpt-exporter/blob/master/src/api.ts), [chatgpt-chat-exporter](https://github.com/rashidazarang/chatgpt-chat-exporter/blob/master/src/extraction-engine.js). Пакет не содержит кода этих расширений и не требует их установки.

## Проверки выпуска

Проверены синтаксис JS/Python, Manifest, состав, CRC и SHA-256 ZIP установочного пакета. Автоматические тесты, браузерные прогоны, вход в ChatGPT и запуск на Windows не выполнялись. Эта проверка не подтверждает реальную загрузку каждого типа вложения в аккаунте.
