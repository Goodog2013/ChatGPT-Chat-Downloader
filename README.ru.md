# Goodog Chat Export 3.2 — Windows · Chrome / Edge

[English](README.md) · [Скачать для Windows](https://github.com/Goodog2013/ChatGPT-Chat-Downloader/releases/download/v3.2.0/GoodogChatExport-Windows-3.2.0.zip)

Расширение сохраняет текущую переписку ChatGPT в ZIP с доступными вложениями или Markdown (.md), импортирует ZIP/JSON и создаёт офлайн HTML-архив. По умолчанию интерфейс английский; русский включается в переключателе языка. Текст сообщений не переводится.

## Установка и обновление

Распакуйте GoodogChatExport-Windows-3.2.0.zip в постоянную папку. Откройте chrome://extensions/ или edge://extensions/, включите режим разработчика и загрузите папку extension. При обновлении замените файлы расширения, нажмите «Обновить» и перезагрузите вкладку ChatGPT. BAT-файлы открывают папку и страницу расширений; настройки безопасности они не меняют. Нужен Chromium 116 или новее. Python, Node.js и API-ключ не требуются.

## Импорт ZIP и HTML-сайт

1. Откройте расширение; для большого архива нажмите «Открыть в широком окне».
2. В локальном импорте выберите ZIP официального экспорта данных ChatGPT, ZIP одного чата из этого расширения либо conversations.json. ZIP предварительно распаковывать не нужно.
3. Для одной переписки выберите чат и формат MD/ZIP. Новый chat.html внутри ZIP оформлен как диалог: сообщения пользователя справа, ответы слева, код, таблицы, изображения и файлы, автоматическая светлая/тёмная тема.
4. Для всех переписок нажмите «Сохранить офлайн HTML-сайт (все чаты)». Распакуйте полученный ZIP и откройте index.html. Боковая панель содержит список и поиск по названиям. Открывается только выбранный чат. На телефоне список доступен по кнопке меню.
5. В chats/ находятся HTML, Markdown, JSON и доступные оригиналы вложений каждого чата. manifest.json содержит отчёт о полноте и ошибках; отчёты отдельных чатов перечисляют SHA-256 файлов. При отсутствии вложений это явно отмечено.

Поддерживаются conversations.json, conversations-N.json и conversation.json в ZIP; архивы HTML-сайта этой версии также можно импортировать повторно. ZIP только с HTML/MD не содержит достаточной структуры для восстановления чата. Для старого распакованного экспорта можно дополнительно выбрать папку вложений. Сопоставляются только однозначные файлы. Недоступные оригиналы из локального ZIP не запрашиваются в интернете.

## Прямой экспорт из ChatGPT

Откройте сохранённую переписку /c/... или /g/.../c/..., выберите ZIP или MD и загрузите историю. Прокрутка не нужна. Для больших чатов оставьте исходную вкладку открытой. ZIP может запросить необязательный доступ к oaiusercontent.com и blob.core.windows.net для оригиналов файлов. При отказе текст сохраняется, а недоступные вложения указываются в отчёте. Можно остановить получение и сохранить доступную часть.

Обычный ZIP содержит chat.html, chat.md, conversation.json, manifest.json, attachments/ и при необходимости previews/. Markdown-вложения открываются через безопасный HTML-просмотр: UTF-8 до 2 МиБ на файл и до 8 МиБ HTML на архив. Более длинные сообщения, превышающие 2 097 152 символа, показываются как исходный текст.

## Полнота, приватность и ограничения

Локальный импорт обрабатывается в памяти вкладки и никуда не загружается. HTML работает после распаковки без сервера и интернета. Он является архивом для чтения, а не подключением к ChatGPT: отправки новых сообщений нет. Исходные ссылки остаются ссылками; внешние изображения автоматически не загружаются. HTML из сообщений экранируется.

Сохраняется текущая ветка каждого чата. Доступные альтернативные видимые узлы остаются в JSON; скрытые инструкции, профиль и внутренние рассуждения исключены. Полнота истории и вложений указаны отдельно. Чаты с ошибками не исчезают молча: в HTML-сайте есть страница ошибки и запись в отчёте.

Пределы локального импорта: ZIP до 8 ГиБ, до 50 000 файлов, суммарно JSON до 512 МиБ, одна переписка JSON до 64 МиБ, до 20 000 переписок. Зашифрованные ZIP не поддерживаются. Проверяются пути, размеры распаковки и CRC-32. Экспорт: до 256 МиБ на вложение и до 1,5 ГиБ на ZIP; для сайта бюджет вложений — 1 ГиБ, остальное оставлено для текста и отчётов. При нехватке бюджета вложение отмечается как недоступное. Превышение лимита текста/ZIP завершает операцию с ошибкой, а не выдаёт урезанный архив за полный. Браузеру нужна дополнительная память; большие архивы лучше обрабатывать в отдельной вкладке.

Marked 18.1.1 (MIT) и zip.js 2.23.0 (BSD-3-Clause) включены локально вместе с лицензиями. Текущие JSON-маршруты ChatGPT могут измениться; официальный экспорт остаётся резервным источником данных.

При публикации v3.2.0 проверялись только синтаксис и целостность установочного пакета. Теперь добавлены регрессионные тесты импорта синтетических ZIP и тест расширения в Chromium; команды и покрытие описаны в [tests/README.md](tests/README.md). Тесты не используют реальный аккаунт ChatGPT или личные выгрузки и не проверяют установку на Windows.
